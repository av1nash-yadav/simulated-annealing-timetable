        📖 What is Simulated Annealing?

        Simulated Annealing (SA) is an optimisation algorithm inspired by the process of annealing in metallurgy — where you heat metal to a high temperature and then slowly cool it down so it settles into a strong, low-energy crystal structure.

        Think of it this way: Imagine you're blindfolded on a hilly landscape trying to find the lowest valley. You start by taking big random jumps (high temperature) so you don't get stuck in a small dip. As you "cool down", your jumps get smaller and you settle into the deepest valley you've found.

        How does it work for timetable scheduling?

        1. Start — Generate a random timetable (each subject goes to a random day, time slot, and room).
        2. Cost function — Count "conflicts":
          • Two subjects in the same room at the same time.
          • Same teacher assigned to two different rooms at the same time.
          The goal is to bring this cost to 0.
        3. Neighbour move — Pick a random subject and move it to a different random (day, slot, room).
        4. Accept or reject —
          • If the new schedule is better (fewer conflicts) → always accept.
          • If it's worse → accept with a probability that depends on temperature. Higher temperature = more likely to accept bad moves (helps escape local minima).
        5. Cool down — Multiply the temperature by the cooling rate (e.g. 0.995). Over time, the algorithm becomes pickier.
        6. Stop — When temperature drops near 0 or we reach 0 conflicts.

        The acceptance formula

        When a neighbour is worse by Δ = new_cost − old_cost, we accept it with probability:

        P(accept) = e−Δ / T

        As T → 0, this probability also → 0, so bad moves stop being accepted.

        Why not brute force?

        Timetable scheduling is an NP-hard problem. The number of possible combinations grows explosively with more subjects, rooms, and time slots. Trying every combination would take an impractical amount of time. SA finds a good enough solution quickly.
